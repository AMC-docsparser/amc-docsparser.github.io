DOCsParser

GitHub 가입 안내

DOCsParser 설치 파일·사용 설명서·의견 게시판은 GitHub의 AMC-docsparser 공간에 있습니다. 처음 한 번만 아래 순서대로 가입하고 초대를 받으면 됩니다. 비용은 들지 않습니다.

한눈에 보기 · 약 10~15분

  1. GitHub 계정 만들기 (무료)
  2. 2단계 인증 켜기 (휴대폰 인증 앱)
  3. 담당자에게 내 사용자 이름 알려 주기
  4. 메일로 온 초대 수락하기
  5. DOCsParser 내려받기 · 게시판 둘러보기

준비물

  • 메일 주소 — 회사 메일 권장 (개인 메일도 됩니다)
  • 휴대폰 — 인증 앱(Microsoft Authenticator 또는 Google Authenticator) 설치용
  • PC 인터넷 브라우저 — Chrome 또는 Edge
1

GitHub 계정 만들기

  1. 브라우저에서 https://github.com/signup 에 들어갑니다.
  2. Email 칸에 메일 주소를 넣고 Continue를 누릅니다.
  3. Password(비밀번호)를 만듭니다.
    • 15자 이상, 또는 8자 이상 + 숫자 1개 + 영문 소문자 1개 이상
    • 회사 시스템 비밀번호와 다른 것으로 정하세요.
  4. Username(사용자 이름)을 정합니다. 화면 주소와 게시판에 표시되는 이름입니다.
    • 영문·숫자·하이픈(-)만 됩니다. 예) hong-gildong, gdhong24
    • 이미 있는 이름이면 빨간 글씨가 나옵니다. 숫자를 붙여 바꿔 보세요.
    • 이 이름을 메모해 두세요. 3단계에서 담당자에게 알려 줍니다.
  5. Country/Region은 South Korea를 고릅니다.
  6. 소식 메일 수신(Email preferences)은 체크하지 않아도 됩니다.
  7. Create account를 누르면 사람 확인 퍼즐이 나옵니다. 화면 안내대로 풀어 주세요.
  8. 가입한 메일함에 GitHub가 보낸 8자리 숫자 코드가 옵니다. 화면에 그대로 입력합니다.
  9. 환영 질문(팀 규모, 관심 분야 등)이 나오면 아무거나 고르거나 Skip으로 건너뜁니다.
  10. 요금제를 묻는 화면이 나오면 무료를 고릅니다 (Continue for free 등). 카드 정보는 넣지 않습니다.
✓ 성공 오른쪽 위에 동그란 프로필 그림이 보이면 가입 완료입니다.
도움말 코드 메일이 5분이 지나도 안 오면 스팸함·광고함을 확인하세요. 회사 메일이 외부 메일을 막는 경우 개인 메일로 가입해도 됩니다.
2

2단계 인증 켜기

비밀번호가 새어 나가도 내 휴대폰이 없으면 로그인할 수 없게 하는 설정입니다. GitHub가 곧 켜라고 요구하므로 처음에 해 두는 것이 편합니다.

  1. 휴대폰에 인증 앱을 설치합니다. Microsoft Authenticator 또는 Google Authenticator (앱스토어·Play 스토어, 무료)
  2. PC에서 https://github.com/settings/security 에 들어갑니다. (오른쪽 위 프로필 그림 → Settings → 왼쪽 Password and authentication)
  3. Enable two-factor authentication을 누릅니다.
  4. 화면에 QR 코드가 나옵니다. 휴대폰 인증 앱에서 + → QR 코드 스캔으로 찍습니다.
  5. 인증 앱에 나온 6자리 숫자를 PC 화면에 입력하고 Continue를 누릅니다.
  6. 복구 코드(Recovery codes)가 나옵니다. Download를 눌러 저장하고, 안전한 곳에 보관합니다.
중요 복구 코드는 휴대폰을 잃어버리거나 바꿨을 때 로그인할 수 있는 유일한 방법입니다. 꼭 보관해 주세요. 휴대폰을 바꿀 때는 인증 앱을 새 휴대폰으로 옮긴 뒤 이전 휴대폰을 초기화하세요.
✓ 성공 이후 로그인할 때 비밀번호 다음에 인증 앱의 6자리 숫자를 묻습니다.
3

담당자에게 사용자 이름 알려 주기

1단계에서 정한 Username(예: hong-gildong)을 사내 메신저나 메일로 DOCsParser 담당자에게 보내 주세요.

보낼 내용이름 · 소속 · GitHub 사용자 이름
예시"홍길동 / ○○팀 / GitHub: hong-gildong 입니다. DOCsParser 초대 부탁드립니다."
도움말 사용자 이름을 잊었다면 GitHub 오른쪽 위 프로필 그림을 누르면 맨 위에 굵게 나옵니다. 비밀번호는 절대 보내지 않습니다.
4

초대 수락하기

  1. 담당자가 초대하면 가입한 메일로 "… invited you to join the AMC-docsparser organization" 메일이 옵니다.
  2. 메일의 Join @AMC-docsparser(또는 View invitation)를 누릅니다.
  3. GitHub 화면에서 Join AMC-docsparser를 누릅니다.
도움말 메일이 안 보이면 로그인한 상태에서 https://github.com/orgs/AMC-docsparser/invitation 에 바로 들어가도 됩니다. 초대는 7일이 지나면 만료됩니다. 만료됐으면 담당자에게 다시 요청해 주세요.
✓ 성공 안내 저장소를 열었을 때 DOCsParser 소개 화면이 보이면 됩니다. "404 This is not the web page you are looking for"가 나오면 아직 초대가 수락되지 않았거나 로그아웃 상태입니다.
5

DOCsParser 내려받기 · 게시판 둘러보기

내려받기

  1. GitHub에 로그인한 브라우저로 내려받기 페이지에 들어가 내려받기를 누릅니다.
  2. 받은 zip을 마우스 오른쪽 단추로 눌러 압축 풀기를 한 뒤, 폴더 안의 install.bat을 더블클릭합니다.
  3. 바탕화면의 DOCsParser로 실행합니다.
도움말 처음 실행할 때 'Windows의 PC 보호' 파란 창이 나오면 추가 정보 → 실행을 누르세요.

의견 게시판에 글 쓰기

  1. 의견 게시판에 들어가 New discussion을 누릅니다.
  2. 분류를 고릅니다 — Ideas(개선 제안), Q&A(질문), Show and tell(사례 공유)
  3. 양식 칸을 채우고 Start discussion을 누릅니다.
지켜 주세요 고객 자료·규격서 원문·사업명·체계명은 게시판에 올리지 않습니다. 화면을 첨부할 때도 이름이 보이지 않게 가려 주세요.

새 버전 소식 받기 (선택)

  1. 안내 저장소 오른쪽 위 Watch → Custom을 누릅니다.
  2. Releases(새 버전)와 Discussions(게시판)를 체크하고 Apply를 누릅니다. 새 버전이 나오면 메일로 알려 줍니다.

자주 묻는 질문

Q. 돈이 드나요?
아니요. 개인 GitHub 계정과 이 공간은 모두 무료입니다. 결제 정보를 넣으라는 화면이 나오면 무료(Free)를 고르면 됩니다.
Q. 회사 메일과 개인 메일 중 무엇으로 가입하나요?
회사 메일을 권장합니다. 회사 메일이 외부 메일을 받지 못하면 개인 메일로 가입해도 됩니다. 나중에 Settings → Emails에서 메일을 추가할 수 있습니다.
Q. 내 정보가 외부에 공개되나요?
사용자 이름과 프로필 그림은 공개됩니다. 실명·회사·소개는 적지 않아도 됩니다. AMC-docsparser 구성원이라는 사실은 기본적으로 다른 구성원에게만 보입니다.
Q. 안내 저장소나 내려받기에서 404가 나와요.
① 로그인 상태인지 ② 4단계 초대를 수락했는지 확인하세요. 둘 다 했는데도 안 되면 담당자에게 사용자 이름을 다시 확인해 달라고 요청하세요.
Q. 비밀번호를 잊어버렸어요.
비밀번호 재설정에서 가입한 메일로 다시 만들 수 있습니다.
Q. 휴대폰을 바꿨더니 로그인이 안 돼요.
2단계에서 저장한 복구 코드로 로그인한 뒤, 새 휴대폰으로 2단계 인증을 다시 설정하세요.
Q. 화면이 이 안내와 조금 달라요.
GitHub 화면 문구는 가끔 바뀝니다. 비슷한 이름의 단추를 누르면 됩니다. 막히면 담당자에게 화면을 보여 주세요.
내려받기 페이지로 이 안내 인쇄 · PDF로 저장
사내 배포용 안내입니다. GitHub 화면 문구는 바뀔 수 있습니다.
